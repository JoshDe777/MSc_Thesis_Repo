## Build and Testing
A build is available for Meta Quest 3 devices (only tested hardware. This maybe works on Quest 2's, but any other device I cannot tell) under the `builds` folder at the project root, called 'vrbeachvb.apk'.
It must be uploaded to a Meta Quest device as an app with unknown source, which requires a Meta Developer account to accomplish.
